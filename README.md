# PickpocketPlus (OBSE64 plugin) — version 0.1

Companion DLL for the PickpocketPlus UE4SS mod. Adds the console command

    PPAddSneakXP <amount>    (short: ppxp)

which gives Sneak XP the same way the game's own pickpocket XP is given.

Install: `Oblivion Remastered\OblivionRemastered\Binaries\Win64\OBSE\Plugins\PickpocketPlus.dll`
Requires: OBSE64, Address Library for OBSE Plugins.

Built with CommonLibOB64 (GPL-3.0, see LICENSE and EXCEPTIONS).
